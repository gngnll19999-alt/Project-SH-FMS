# SH-FMS 화면설계서

| 항목 | 내용 |
|---|---|
| 문서번호 | SH-FMS-UI-2026-001 |
| 버전 | Rev.3 (2026-09-21) |
| 기준 해상도 | 관제실 3840×2160 / 사무 1920×1080 (최소 1440×900) |

## 1. 설계 기준

이 화면은 **예쁘게 만들면 안 된다.** 1차 관제 화면이 실패한 이유가 그것이었다.
상태마다 색을 다 넣어서 화면이 알록달록했고, 정작 이상이 발생해도 눈에 안 띄었다.

ISA-101 고성능 HMI 원칙을 그대로 따른다.

### 색 예산

| 용도 | 색상 | 값 | 사용 범위 |
|---|---|---|---|
| 배경 | 다크 | `#0b0e12` | 전체 |
| 패널 | | `#141920` | 카드 |
| 텍스트 | 저채도 회색 | `#c9cfd8` | **정상 공정값 전부** |
| 경고 | 앰버 | `#d6a02c` | H / L 한계 접근 |
| 알람 | 레드 | `#d6483c` | HH / LL 초과, 트립 |
| 조치 필요 | 블루 | `#4a86d8` | 조작자 확인 대기 |
| 정상(상태만) | 뮤트 그린 | `#4f9e63` | 가동 표시등 |
| 브랜드 | 시안 | `#35c0d6` | **네비게이션 전용** |

> 시안은 로고·메뉴·선택 표시에만 쓴다. 공정 데이터에 쓰면 "봐야 할 색"이 희석된다.

### 화면 계층

| 계층 | 화면 | 목적 |
|---|---|---|
| Level 1 | 공장 전체 감시 | 한눈에 이상 유무 판단 |
| Level 2 | 라인 미믹 / 화학 배치 / 에너지 | 유닛 단위 일상 운전 |
| Level 3 | CCTV / 안전 관제 | 개별 상세 · 영상 확인 |
| Level 4 | 알람 관리 / 트렌드 | 진단 · 분석 |

```
┌──────────────────────────────────────────────────────────────┐
│ [P1] CT02_TT401 건조로 온도 상한상한 초과    미확인 5건 (P1 2) │  30px  알람 배너
├──────────┬───────────────────────────────────────────────────┤
│ SH-FMS   │ 화면명 · 구역   LEVEL 표시  OPC UA 상태  시계  사용자│  48px
├──────────┼───────────────────────────────────────────────────┤
│  좌측     │                                                   │
│  메뉴     │              본문 (스크롤)                         │
│  198px    │                                                   │
└──────────┴───────────────────────────────────────────────────┘
```

**알람 배너**는 어느 화면에 있어도 최상단에 고정된다. 클릭하면 알람 관리로 이동한다.
이게 이번 설계에서 가장 중요한 요소다 — 2026-05-14 사고의 직접 원인이 화면 전환이었다.

좌측 메뉴는 ISA-101 계층으로 묶는다. 알람 메뉴에는 미확인 건수 배지가 붙는다.

## 3. 화면별 설계

### F-01 공장 전체 감시 (Level 1)

| 영역 | 구성 |
|---|---|
| 상단 | KPI 6종 — 가동설비 / 미확인알람 / 생산달성률 / OEE / 순간전력 / 무재해일수 |
| 2단 | 동별 설비 상태 보드 (A·B·C·D동) — 설비별 점 표시등 + OEE |
| 3단 | 핵심 공정값 타일 18종 (6열) — **정상은 무채색**, 경고 앰버, 알람 레드 |
| 하단 | 활성 알람 요약 / 영상 4분할 / 유틸리티 + 전력 추이 |

공정값 타일 구성: 태그명(모노) · 설명 · 값(대형 모노) · SP/L/H 범위.
좌측 2px 리본으로 상태를 표시한다.

### F-02 라인 공정 미믹 (Level 2)

SVG 미믹 2종을 라인 선택으로 전환한다.

**코팅 라인** — 언와인더 → 코팅 다이(+슬러리 탱크) → 건조로 3존 → 리와인더 → 비전검사 → 포장
**배합 라인** — 원료 사일로 3기 → 칭량 호퍼 → 반응기 R-101/R-201 → 충전·포장

- 배관에 흐름 도트 애니메이션. 정지 라인은 점선 + 애니메이션 정지
- 공정값은 설비 근처에 오버레이, 이상 시에만 색
- 하단에 공정 단계 진행바
- 우측에 구동부 상태(운전/정지/트립 + 부하율)와 최근 상태 변화 로그

> 갱신은 **값 노드만 부분 교체**한다. SVG 전체를 다시 그리면 1초마다 화면이 깜빡여서
> 운전원이 못 본다. (현장 시연 피드백, 09-19)

### F-03 화학 배치 공정 (Level 2)

| 영역 | 구성 |
|---|---|
| 상단 | 반응기 카드 2기 — SVG 용기(레벨·교반축·자켓) + 페이즈 진행 + 공정값 4종 |
| 중단좌 | 배치 트렌드 (온도 실적 vs 설정 vs 자켓) + 압력 |
| 중단우 | 인터록 상태 (감시 전용) |
| 하단 | 공정조건 준수율 / 배치 이력 |

용기 SVG는 레벨을 채움 높이로, 교반 가동을 모터 점멸로, 자켓 가열/냉각을 테두리 색으로 나타낸다.

### F-04 에너지 · 유틸리티 (Level 2)

| 영역 | 구성 |
|---|---|
| 상단 | KPI 6종 (금일전력 / 순간전력 / 최대수요 / 스팀 / 용수 / 배출량) |
| 중단좌 | 시간대별 전력 + 스팀. 피크 경고선(1,440kW) 표시 |
| 중단우 | 실시간 유틸리티 + 역률/수전전압/최대수요 |
| 하단 | 구역별 사용량 막대 / 구역별 상세표(원단위·전일대비·스파크라인) |
| 최하단 | 온실가스 도넛 / 15분 수요전력 / 절감 과제 |

### F-05 CCTV 통합관제 (Level 3)

```
┌────────────────────────────────┬──────────────┐
│  영상 월 (1/4/9/12 분할)        │ 카메라 목록   │
│  ┌──────┬──────┐               │              │
│  │ CAM  │ CAM  │               ├──────────────┤
│  ├──────┼──────┤               │ PTZ 제어     │
│  │ CAM  │ CAM  │               │  ↖ ↑ ↗      │
│  └──────┴──────┘               │  ← ▣ →      │
├────────────────────────────────┤  ↙ ↓ ↘      │
│  녹화 타임라인 (24h)            ├──────────────┤
│  ▓▓▓░░▓▓█▓▓▓▓▓█▓▓▓▓▓▓▓│       │ AI 이벤트    │
└────────────────────────────────┴──────────────┘
```

- 타일: 영상 + 하단 바(녹화 점등 / 카메라명 / PTZ·AI 배지). 이벤트 발생 카메라는 적색 테두리
- 더블클릭 시 단일 화면 전환
- 타임라인: 녹화 구간(청) / 이벤트 구간(적) / 현재 시각 커서(시안). 클릭 시 해당 시각 재생
- PTZ: 8방향 + 줌 + 프리셋 4개. **고정형 카메라와 조회전용 계정은 비활성**
- 순차 감시: 10초 간격 자동 전환

### F-06 안전 관제 (Level 3)

| 영역 | 구성 |
|---|---|
| 상단 | KPI 5종 (무재해일수 / 아차사고 / 작업허가 / 보호구 미착용 / 재실인원) |
| 2단 | 구역별 안전 카드 6개 — 위험요인 · 재실인원 · 가스 · 화재 |
| 3단 | 안전 이벤트 목록 / 작업허가서(PTW) |
| 하단 | 법정 점검 이력(기한 경과 적색 강조) / 가스 검지기 + VOC 추이 |

### F-07 알람 관리 (Level 4)

| 영역 | 구성 |
|---|---|
| 상단 | KPI 5종 (미확인 / P1 / 금일발생 / 시간당최대 / 셸빙중) |
| 필터 | 우선순위 · 구역 · 상태 + 일괄 ACK/셸빙 + 알람철학 문서 |
| 중단 | 알람 목록 — P1 미확인 행은 배경 강조, 확인된 행은 투명도 down |
| 하단좌 | 알람 부하 차트 (시간당 목표 6건 초과 구간 앰버) |
| 하단우 | 빈발 알람 상위 6 + 개선 조치 |

알람 행 구성: 등급 · ID · 발생시각 · 태그 · 구역 · 유형 · 메시지 · 경과 · 상태 · 조치 버튼

### F-08 트렌드 · 히스토리안 (Level 4)

| 영역 | 구성 |
|---|---|
| 필터 | 기간 · 샘플링 + CSV 내보내기 · 그룹 저장 |
| 좌상 | 트렌드 (최대 6개 태그, 저채도 팔레트) |
| 좌하 | 통계표 (현재/최소/최대/평균/표준편차/범위이탈) |
| 우상 | 태그 선택 목록 (체크박스 + 색 스와치) |
| 우하 | 저장된 트렌드 그룹 |

단위가 서로 다르므로 각 태그의 운전범위(LL~HH)를 0~100%로 정규화해 겹쳐 그린다.

## 5. 성능 관련 설계

| 항목 | 방식 | 이유 |
|---|---|---|
| 태그 갱신 | SignalR 푸시 (폴링 아님) | 관제 PC 6대 × 1초 폴링이면 서버가 쓸데없이 바쁨 |
| 미믹 갱신 | 값 노드만 교체 | 전체 재그리기 시 깜빡임 |
| 트렌드 포인트 | 최대 600점 균등 샘플링 | 600점 넘으면 픽셀이 겹침. 전송량만 증가 |
| 구독 범위 | 구역 단위 그룹 | A동 관제 PC 에 B동 태그를 보낼 이유 없음 |
| 차트 | 자체 SVG | 폐쇄망 CDN 불가 |
