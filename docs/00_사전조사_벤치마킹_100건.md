## 0. 조사 목적과 방법

당사 화성1공장(전자재료·정밀화학)과 아산2공장(부품조립) 통합 시스템 재구축을 앞두고,
**"무엇을 만들 것인가"를 우리 머리로 정하지 않기 위해** 국내외에서 실제로 운영 중인
패키지의 기능 범위와 표준 문서를 먼저 조사했다.

조사 대상은 크게 네 갈래다.

1. **국제 기능표준** — MESA-11, ISA-95(IEC 62264), ISA-88, ISA-101, ISA-18.2
2. **글로벌 패키지** — SAP S/4HANA, Siemens Opcenter Execution, Rockwell Plex MES, AVEVA System Platform, Ignition
3. **국내 패키지** — 더존 iCUBE / WEHAGO, 영림원 K-System Ace, 이카운트 ERP, 아이퀘스트 얼마에요,
   미라콤 Nexplant MESplus, 삼성SDS Nexplant, LG CNS Factova, 각 MES/POP 전문업체
4. **국내 법규·제도** — 전자세금계산서(국세청), HACCP(식약처), 중대재해처벌법, 스마트공장 수준확인, IATF 16949

아래 100건은 그 결과를 **"우리 시스템에 넣을 것 / 넣지 않을 것"** 판단이 가능한 단위로 쪼갠 것이다.
각 행의 `반영` 열이 실제 설계 반영 여부이며, 이 표가 그대로 요구사항정의서의 입력이 된다.

- 반영 표기: `MES` / `ERP` / `FMS`(모니터링) / `보류`(2차 과제 이월) / `제외`

## A. MES 실행계 기능 (1 ~ 30)

MESA International이 1997년 정의한 11대 기능모델(MESA-11)을 뼈대로 잡고,
Opcenter·Plex의 실제 메뉴에서 빠진 것을 채웠다.

## B. ERP 관리계 기능 (31 ~ 62)

SAP S/4HANA의 모듈 구획을 뼈대로, 국내 중견기업 실무(더존 iCUBE·영림원 K-System·이카운트)에서
실제로 매일 쓰는 화면을 우선순위로 올렸다. 국내 ERP는 **전자세금계산서·4대보험·연말정산**이
빠지면 아예 못 쓰는 시스템이 되므로 이 부분을 글로벌 패키지보다 비중 있게 잡았다.

## C. 공장 모니터링 / SCADA / CCTV (63 ~ 85)

ISA-101(HMI 설계), ISA-18.2(알람 관리)를 기준으로 삼았다.
여기서 나온 "고성능 HMI" 원칙이 SH-FMS 화면이 왜 회색 위주인지에 대한 근거다.

## 1. 조사 결과 요약 — 우리가 내린 결론 5가지

**① MES 메뉴는 MESA-11을 그대로 따르되, 현장이 쓰는 말로 바꾼다.**
"Dispatching Production Units"를 그대로 번역해 걸면 현장에서 아무도 안 누른다.
`작업배정`, `POP 현장단말` 같은 국내 통용어로 라벨링하고, 문서에만 표준 매핑을 남긴다.

**② POP 화면은 Plex의 작업자 컨트롤 패널 구성을 베이스로 한다.**
자재확인 → 셋업체크 → 공수 → 공구수명 → 실적/수율 → SPC 순서가 이미 검증된 동선이다.
당사는 여기에 4M 변경점 등록을 추가한다(IATF 대응).

**③ ERP는 글로벌 모듈 구획(FI/CO/SD/MM/PP) + 국내 필수 3종을 붙인다.**
국내 필수 3종 = 전자세금계산서, 4대보험·연말정산, 여신한도.
이게 빠지면 아무리 잘 만들어도 경리팀이 병행해서 다른 프로그램을 쓴다.

**④ 모니터링 화면은 ISA-101 고성능 HMI 원칙을 지킨다.**
평상시 회색, 이상시에만 색. 알람은 ISA-18.2 부하 목표(시간당 6건)를 KPI로 화면에 띄운다.
"예쁜 대시보드"를 만들면 운전원이 이상을 못 찾는다는 게 이 표준의 요지다.

**⑤ 화학 라인은 ISA-88 레시피 구조를 반드시 넣는다.**
당사 배합 공정은 현재 엑셀 배합지시서로 돌고 있는데,
마스터/컨트롤 레시피 개념 없이 MES를 만들면 제품 바뀔 때마다 개발자를 불러야 한다.
